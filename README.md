# Algorand Project

## About the Project
This repository is created as part of the Algorand course to develop and maintain an Algorand blockchain project.

## Objectives
- Understand the Algorand blockchain ecosystem.
- Learn how Algorand transactions and smart contracts work.
- Develop and test an Algorand-based application.
- Maintain the complete project development using GitHub.

## Technologies
- Algorand Blockchain
- Algorand TestNet
- Algorand SDK
- Python
- GitHub

## Project Status
Project development is in progress.
